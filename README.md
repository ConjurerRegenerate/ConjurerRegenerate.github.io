# MTProxy Лист

> 74 рабочих MTProxy для Telegram — живой список с проверкой пинга.

[![Сайт](https://img.shields.io/badge/сайт-conjurerregenerate.github.io-9d2538)](https://conjurerregenerate.github.io/)
[![Канал](https://img.shields.io/badge/Telegram-@mtprxtg-2aabee)](https://t.me/mtprxtg)

## Что внутри

- `74` проверенных прокси-серверов MTProxy: наши серверы @mtprxtg + отобранные публичные;
- проверка доступности прямо на странице (кнопка «Проверить все»);
- подключение в один клик — Telegram открывается сам;
- сайт устанавливается на телефон как приложение (PWA).

**Открыть список:** [https://conjurerregenerate.github.io/](https://conjurerregenerate.github.io/)

## Подключение вручную

Telegram → Настройки → Данные и память → Прокси → MTProto — или просто нажмите «Подключить» на сайте.
